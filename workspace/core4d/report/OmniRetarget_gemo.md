# Q: OmniRetarget 优化时和手部碰撞体有关系吗?

# A
有关系,但很弱、很间接——而且默认配置下几乎不约束手-箱接触面。 分两个层面:

## 1. 非穿透约束(默认开)——手部 geom 会参与,但只防穿透,不管"贴合"
OmniRetarget 的非穿透硬约束(activate_obj_non_penetration=True)流程(_update_jacobians_and_phis_from_q):
1. mj_collision 粗筛出候选 geom 对;
2. masks_ok 过滤:只保留"机器人 geom ↔ object" 或 "机器人 geom ↔ ground" 的对(:1252-1267);
3. 对这些对算 mj_geomDistance,距离 < 阈值就加一条线性化的非穿透约束 φ(q)≥0。

所以只要机器人手部有碰撞 geom,它就会被纳入"手不许插进箱子"的约束。这就是为什么手部碰撞体和 OmniRetarget 有关系。

但关键限制:
- 这是几何带符号距离约束,不是接触力(纯运动学,见之前调研)。
- 它只单向防穿透(φ≥0),不奖励"贴近"——手停在箱外 1cm 和停在箱外 20cm,对非穿透约束都满足、没有区别。
- 用的碰撞 geom 就是 robot XML 里定义的那个(task_constants.ROBOT_URDF_FILE → 对应 .xml)。OmniRetarget 用的 G1 模型里 L_Wrist/R_Wrist 映射到 rubber_hand_link——它的碰撞 geom
形状决定了"手能多贴近箱而不触发穿透约束"。如果那是个大球,手会被推得离箱更远;如果是贴手形 mesh,能更贴。

## 2. 接触保持(Phase 4c,enable_contact_preservation)——默认关闭

代码 :483-492 有个 contact preservation 项:对 L_Wrist/R_Wrist 算"wrist 到物体中心的距离",作软目标拉近。但 enable_contact_preservation=False 默认关(:70),w_contact=20
也只在开启时生效。

而且它用的是 wrist 到物体中心的距离,根本不涉及手部碰撞体的形状——这是 B6(wrist≠contact)那条线。

## 3. interaction mesh(主目标)——完全不用手部碰撞体

OmniRetarget 的核心目标是 Laplacian 形变能量,顶点是关节点 + 物体表面采样点(见之前调研),用的是 joint 位置,不是碰撞 geom。所以主优化目标和手部碰撞体形状无关。

一句话:OmniRetarget 优化时,手部碰撞体只通过"非穿透约束"间接起作用——它决定"手最多能贴箱多近而不被判穿透",但不主动把手往箱上贴(那是靠 Laplacian 拉关节)。所以:
- OmniRetarget 里换更贴的碰撞体(球→mesh),效果是让手能合法地更贴近箱(约束放松),但因为没有"贴近奖励",净效果有限。
- 真正靠碰撞体形状决定接触质量的是 SPIDER 的物理 CEM——这也是为什么"换 rubber 碰撞体重跑 CEM"比"在 OmniRetarget 层换"更可能见效。

这一点也修正/补充了我们之前在 ReActor 文档 §1.6(c) 里写的"可在 OmniRetarget 层修参考"——对接触目标点位置(B6/Laplacian 权重)那条成立,但对碰撞体形状这条,OmniRetarget 的杠杆很弱,主战场在
SPIDER CEM。
