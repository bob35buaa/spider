# E036: HDMI Reward Alignment — 去掉 hand_approach，开启 Object Tracking

## Context

E035 实现了 local-frame body tracking，打破了 stability/contact tradeoff（3/3 cases 零摔倒 + desk005 contact<10cm=94.8%）。但 **body tracking 精度极差**：MPKPE=48cm（目标 <15cm，HDMI=7.7cm）。

**根因**（E035 log 分析）：
- `hand_approach_rew` max=5.0 > `local_frame_rew` max=3.5
- CEM 花费主要 budget 优化"手靠近物体"而非"身体跟踪 ref"
- HDMI 不需要 hand_approach — 它用 **contact mask 门控的 rew_contact + object global tracking** 替代
- HDMI 不需要 stability_penalty — contact 有 mask 所以不会在不该接触时前倾

**本实验目标**：对齐 HDMI 的 reward 结构，**去掉贡献过大的 hand_approach**，让 CEM 全力优化 body tracking。

## 方案：config-only 改动 + 修复 nq_obj==6 的 task_obj_rew

### 改动 1: YAML 配置 (core4d_e036.yaml)

```yaml
# 核心变化：去掉 hand_approach + stability_penalty
hand_approach_rew_scale: 0.0        # 关闭！（从 5.0 → 0.0）
stability_penalty_scale: 0.0        # 关闭（不需要了，local frame不会前倾）

# 开启 object global tracking（HDMI 风格）
task_obj_pos_rew_scale: 1.0         # 跟踪物体位置
task_obj_rot_rew_scale: 1.0         # 跟踪物体朝向

# 保持 local-frame body tracking
use_local_frame_reward: true
local_frame_w_track: 0.5            # 不变
local_frame_pos_sigma: 0.5
local_frame_ori_sigma: 1.0
local_frame_root_sigma: 0.5
local_frame_joint_sigma: 0.25
```

**Reward budget 分析**：
- local_frame_rew max = 0.5 * 7 = 3.5 (body tracking)
- task_obj_rew: `-scale * pos_err²` (负值，惩罚式) — 不与 tracking 竞争上限
- Total: CEM **唯一的正向 reward 来自 body tracking** → 必然优化 MPKPE

### 改动 2: 修复 task_obj_rew 的 nq_obj==6 分支 (mjwp.py:593-614)

**问题**：当前代码只处理 `nq_obj == 7` (freejoint)，但 E035 配置 `contact_guidance: true` → `nq_obj = 6` (3pos + 3euler)。需要添加 `nq_obj == 6` 的分支。

```python
# 现在 (line 605):
if nq_obj == 7:
    obj_pos_sim = qpos_sim[:, -7:-4]
    ...

# 改后:
if nq_obj == 7:
    obj_pos_sim = qpos_sim[:, -7:-4]
    obj_pos_ref = qpos_ref[-7:-4].unsqueeze(0)
    ...
elif nq_obj == 6:
    obj_pos_sim = qpos_sim[:, -6:-3]
    obj_pos_ref = qpos_ref[-6:-3].unsqueeze(0)
    pos_err = ((obj_pos_sim - obj_pos_ref) ** 2).sum(dim=-1)
    task_obj_rew = task_obj_rew - config.task_obj_pos_rew_scale * pos_err
    if config.task_obj_rot_rew_scale > 0.0:
        obj_euler_sim = qpos_sim[:, -3:]
        obj_euler_ref = qpos_ref[-3:].unsqueeze(0)
        rot_err = ((obj_euler_sim - obj_euler_ref) ** 2).sum(dim=-1)
        task_obj_rew = task_obj_rew - config.task_obj_rot_rew_scale * rot_err
```

## Claims

1. **C1**: MPKPE < 20cm (从 48cm 下降 >50%)。依据：去掉 hand_approach 后 CEM 唯一正向 reward 是 body tracking。
2. **C2**: Stability >0.60m 维持 ≥ 90%。依据：local-frame tracking 已证明可保持稳定性（E035 3/3=100%）。
3. **C3**: Object tracking improvement（Obj Pos Error 应优于 E035 的 22.5cm desk005 / 16.8cm box025）。依据：新增 task_obj_rew 显式惩罚物体偏离。

## 风险

1. **去掉 hand_approach 后 contact 可能大幅退化** — 没有任何激励手靠近物体。这是预期的，下一步（E037）会用 contact mask 门控的 HDMI 风格 rew_contact 恢复。
2. **task_obj_rew 使用负值惩罚** (−scale * err²) — 如果物体本身被 PD override/contact_guidance 驱动（它确实是），这个 reward 可能是冗余的。但至少能让 CEM 偏好不干扰物体轨迹的动作。
3. **去掉 stability_penalty 后是否仍稳定** — E035 已证明 local-frame 本身稳定，但那时 hand_approach 还在。去掉后 CEM 没有"拉手"动机，理论上更稳定。
