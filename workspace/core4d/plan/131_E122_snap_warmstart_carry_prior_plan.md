# E122 Snap Warmstart Carry Prior Plan

Date: 2026-06-03

## Context

`contact_improvement_plan.md` requires high true contact, low deep penetration, stable posture, and lower-body/object strict pass before any RL handoff.

E115-E121 have narrowed the Box021 blocker:

- E115/E117 lower-body penalties can remove leg contact, but physics hand contact collapses.
- E118/E119 corridor/upright rewards can improve contact on some rows, but main `box021_029_p2` still falls into lower-body, penetration, or posture failure.
- E120 explicit support decomposition added the right metrics, but main `box021_029_p2` still reached only 29.3-37.3% physics contact with 30.7-36.0% non-hand support.
- E121 terminal carry gate showed that terminal elite filtering alone is insufficient: main `box021_029_p2` reached only 32.0/32.0/28.0% physics contact, and hard-ref starved the CEM gate.

The remaining hypothesis is that main `box021_029_p2` needs the rollout distribution changed before terminal selection. E122 tests the smallest existing mechanism for that: `warmstart_qpos_path`, generated by arm-only object-surface snap IK, combined with the E120/E121 support/carry metrics.

## Claims

### C1: warmstart generation is reproducible

For each E120/E121 workset case, E122 must generate one `warmstart_qpos.npz` with:

- `qpos_snap` shape equal to the source `trajectory_kinematic.npz` qpos shape;
- non-empty `snap_mask`;
- finite `qpos_snap`;
- snap diagnostics showing hand-to-surface distance improved in the intent window.

### C2: warmstart changes the early CEM reference manifold

Each E122 override must set `warmstart_qpos_path` and `warmstart_update_ctrl_from_qpos=true`, then inherit the corresponding E121 support/carry configuration. This isolates the new variable to snap warmstart plus terminal-gate on/off.

### C3: smoke gate determines full CEM

Full CEM is allowed only if the main `box021_029_p2` smoke result improves over both E120 and E121:

- physics contact > E120 best main value 37.3%, preferably >=57%;
- lower-body/object interference < E120 best main value 18.7%, preferably <=5%;
- non-hand object support < E120 best main value 30.7%, preferably <=5%;
- `pelvis_ok=True` or visual posture clearly better than E120/E121;
- deep penetration does not regress by more than +3pp;
- hard-gated variants must not rely on near-total fallback.

If main smoke does not pass this gate, do not launch E122 full CEM.

## Mechanism

E122 uses existing code rather than adding a new optimizer scheduler:

- `examples/run_mjwp.py` already supports `warmstart_qpos_path`.
- E122 adds `warmstart_update_ctrl_from_qpos`, default `false`, so only E122 can optionally update robot `ctrl_ref` from snapped robot qpos in the same `snap_mask` frames. This makes the CEM initial control mean consistent with the snapped reference while keeping historical warmstart behavior unchanged.
- `spider/preprocess/hand_snap_ik.py` provides arm-only snap IK to object surface.
- E120 support decomposition metrics and E121 terminal/fallback metrics remain mandatory evaluator outputs.

The initial checked main-case warmstart probe:

- generated `qpos_snap` shape: `(75, 43)`
- hand-to-surface final distance mean: about 1.4cm
