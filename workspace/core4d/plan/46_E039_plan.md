# E039 Plan: HDMI-Aligned Contact Reward with Predefined Contact Points

## Context

E037 sweep 证明当前的 box-SDF + approach_mask 方案只能提供微弱改善 (+1-2%)。
核心差异在于 HDMI 使用 **预定义的精确接触点** 而非粗略的 box 表面距离。

本实验完全对齐 HDMI 的 contact reward 设计:
1. 预定义 contact_target_offset (物体局部坐标系中的接触点)
2. 预定义 contact_eef_offset (EEF 上的接触探测点)
3. Per-EEF 分别计算 reward (非 min over hands)
4. 使用 ref 中的 object_contact mask (基于 FK 距离预计算)
5. 非接触帧 reward=1.0 (HDMI exact)

## 从 ref 提取的接触点

通过 FK 分析 ref 中手距物体 <15cm 的帧, 计算手在物体局部坐标系的平均偏移:

| Case | Left target (obj local) | Right target (obj local) |
|------|------|------|
| box025 | [0.24, 0.27, -0.49] | [-0.24, 0.26, -0.49] |
| desk005 | [-0.11, 0.38, 0.47] | [0.05, 0.38, 0.46] |
| bucket010 | [-0.24, 0.30, -0.18] | [-0.20, 0.31, 0.14] |

EEF offset (G1 wrist → 手掌中心, 与 HDMI 一致): `[0.05, 0.0, 0.0]` per hand

## 改动

### 1. config.py — 新增字段

```python
# E039: HDMI-aligned contact reward with predefined points
contact_hdmi_gain: float = 0.0  # 0=disabled; HDMI uses 5.0
contact_hdmi_sigma: float = 0.3  # same as HDMI eef_pos_sigma
contact_hdmi_target_left: list[float] = field(default_factory=list)  # [x,y,z] in obj local
contact_hdmi_target_right: list[float] = field(default_factory=list)
contact_hdmi_eef_offset: list[float] = field(default_factory=lambda: [0.05, 0.0, 0.0])
```

### 2. mjwp.py — 新 reward 块 (替代 contact_mask_rew)

```python
# E039: HDMI-aligned contact — predefined target + per-EEF + mask gate
if config.contact_hdmi_gain > 0.0 and config.contact_hdmi_target_left:
    # Get sim EEF pos & quat
    xpos_sim = wp.to_torch(env.data_wp.xpos)
    xquat_sim = wp.to_torch(env.data_wp.xquat)
    obj_pos = xpos_sim[:, obj_body_id]  # (N, 3)
    obj_quat = xquat_sim[:, obj_body_id]  # (N, 4) wxyz
    
    # Target = obj_pos + rot(obj_quat, target_offset)
    for eef_idx, (bid, target_off) in enumerate(zip(eef_body_ids, [left_target, right_target])):
        eef_pos = xpos_sim[:, bid]  # (N, 3)
        eef_quat = xquat_sim[:, bid]  # (N, 4)
        
        # Target in world = obj_pos + quat_apply(obj_quat, target_offset)
        target_world = obj_pos + quat_apply(obj_quat, target_off)
        # EEF contact point = eef_pos + quat_apply(eef_quat, eef_offset)
        contact_point = eef_pos + quat_apply(eef_quat, eef_offset)
        
        dist = (target_world - contact_point).norm(dim=-1)  # (N,)
        pos_rew = torch.exp(-dist / sigma)
        per_eef_rew.append(pos_rew)
    
    # Combine per-EEF with mask
    rew_stack = torch.stack(per_eef_rew, dim=1)  # (N, 2)
    # mask: per-EEF contact mask from ref
    contact_hdmi_rew = (rew_stack * mask * gain + (1.0 - mask)).mean(dim=1)
```

### 3. run_mjwp.py — 预计算 per-EEF contact mask

从 ref FK 预计算每帧每只手是否在接触:
```python
# Per-EEF mask: (T, 2) — 左手 mask + 右手 mask
per_eef_contact_mask[t, eef_idx] = 1.0 if dist(eef, target) < threshold
```

### 4. core4d_e039.yaml — per-task 配置

每个 task 有不同的 contact_target, 通过 hydra override:
```yaml
contact_hdmi_gain: 5.0
contact_hdmi_sigma: 0.3
contact_hdmi_target_left: [0.24, 0.27, -0.49]  # box025
contact_hdmi_target_right: [-0.24, 0.26, -0.49]
contact_hdmi_eef_offset: [0.05, 0.0, 0.0]
```

## Claims

1. **C1**: Contact<10cm ≥ 70% on box025 (从 57% → 70%+)
2. **C2**: MPKPE < 3cm (允许少量退化)
3. **C3**: Stability > 90%

## 风险

- gain=5.0 > tracking max(3.5) → 可能重蹈 E035 (body tracking 退化)
- 需要可能降低 gain 到 3.5 作为 fallback
