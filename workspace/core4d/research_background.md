# 1. My proposal (研究背景)
题目（拟定，仅代表大方向）：面向人机协作的动力学重定向方法
近年来，得益于深度强化学习和控制理论的发展，以人形机器人为代表的具身智能体在单体运动控制方面已展现出高度的稳定性，并在灵巧操作任务中表现出日益增强的多样性与鲁棒性。然而，具身智能体的核心价值不仅在于独立完成任务，更在于融入人类社会，在家庭服务、康复护理、工业制造等场景中与人类并肩工作。在这些典型的人类生活与工作场景中，如室内家具搬运、装配、递物等，单纯的独立作业能力已无法满足需求，人机物理协作（Physical Human-Robot Collaboration, pHRC）成为了亟待解决的关键问题，因此，本文探索人机协作新模式，使具身智能能够理解人类意图，辅助于人，服务于人，更好地与人类共同完成任务。
人机物理协作是属于人机交互范畴内的概念，典型的人机交互依据交互方式可以分为三种递进的典型范式：社会交互、直接交互和间接交互。社会交互范式属非物理接触范畴，侧重于认知层的社交信号的自然传递与人类社交意图的精准解析，典型任务如打招呼、鞠躬等。直接交互涉及与人体短暂且低频的直接物理接触，其核心挑战在于交互意图预测以及机器人的本体安全合规控制，如握手、拥抱、协助起身等典型任务。间接交互即本研究讨论的范畴：人机协作，该场景是一个持续、高频及动态的物理接触过程，具有天然的协作性和长程性，要求机器人系统既具备深层次的协作意图理解和空间理解能力又具备复杂环境下的动态协同控制能力，典型任务如协作搬运、协作装配和递物。
人机物理协作本质是一个具有高度不确定性的动态交互过程，在协作的过程中，具身智能体（在本项目内特指人形机器人）需要面对各种地形保持稳定鲁棒的控制，还需要对人类的动态变化做出适应性响应。现有的人形机器人单体运控操作技术难以直接应用到人机协作场景，尤其是在低层的运动控制方面，现有方法人机交互动作的物理合规性差，一个重要的研究前提是基于人类动捕数据进行动作重定向（Retarget）。
OmniRetarget通过动作重定向将人类动捕数据迁移到人形机器人的全身运动控制，展现出具有前景的效果和应用价值。然而，此方法在接触丰富的人机交互、人机协作场景下的物理合规性差，没有明确维护空间和接触关系，从而导致接触关系失真，并产生脚滑和穿模等伪影，难以为人机协作提供物理合规的高质量参考运动数据支撑。

## 2. 前期工作和相关背景

### 2.1 跑通基于OmniRetarget的pipeline
项目位于@/home/ubuntu/Workspace/holosoma，完成了从 人-物-人动捕数据的运动学重定向和RL训练，发现问题的瓶颈在于重定向:
```
CORE4D 人体数据 → OmniRetarget (IK + Interaction Mesh) → G1 retarget 数据
                                                            ↓
                                                    手在箱子底部 (z≈-0.5)
                                                    0% 侧面夹持
```
本质矛盾：OmniRetarget 是纯运动学方法。Interaction Mesh 保持了"相对空间拓扑"，但 G1 比人矮（1.32m vs ~1.7m），手臂更短。在按比例压缩拓扑后，G1 的手只能触及箱子底边——这是运动学可达性极限，不是优化参数问题。因此需要更好的重定向&动力学重定向。
