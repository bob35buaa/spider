# E032: Case 对比分析 — box025 vs desk005 优化难度评估

## 目标修正

目标**不是匹配 ref**，而是产出**物理合规的搬运轨迹**供 RL 训练：
- 在搬运阶段（carrying phase），手应持续紧贴物体表面
- 接触应该是持续的、稳定的承重接触
- 机器人同时保持稳定行走

## Ref 动作阶段分析

### box025 (4.1s)
```
[0.0-0.5s] 接近阶段: 手在物体 18cm 外 (approaching)
[0.5-3.8s] 搬运阶段: 手贴着箱面 (carrying) — 3.3s
[3.8-4.1s] 放下阶段: 手离开
```
搬运阶段内 ref 接触质量:
- contact<10cm = **85%** (手几乎全程贴着)
- contact<5cm = 64%
- mean_surf = **0.04m** (平均仅 4cm)

### desk005 (3.9s)
```
[0.0-0.3s] 接近阶段
[0.3-3.6s] 搬运阶段: 手在桌面 12-13cm 外 (carrying) — 3.3s
[3.6-3.9s] 放下阶段
```
搬运阶段内 ref 接触质量:
- contact<10cm = **0%** (手从未进入 10cm!)
- contact<15cm = 100% (全程在 12-15cm 间)
- mean_surf = **0.13m** (平均 13cm)

## 核心差异

| 维度 | box025 | desk005 |
|------|--------|---------|
| **Ref 搬运方式** | 手紧贴箱面推/搬 (mean 4cm) | 手悬在桌面 12cm 上方"扶着走" |
| **接触要求** | 需要 <5cm 持续接触 | 需要 <15cm 稳定保持距离 |
| **关节极端性** | max 1.85rad (深度弯腰) | max 0.79rad (正常步态) |
| **行走速度** | 0.51 m/s (慢) | 0.60 m/s (快) |
| **当前成绩** | E027d2: 65% contact<10cm (搬运期) | E032a: 83% contact<10cm |
| **当前瓶颈** | HA 破坏姿态; 无 HA 只有 65% | 79% stable (base=10 反而更差) |

## 优化难度评估

### desk005 — 接触已超标，核心问题是稳定性

**已达成**: E032a 的 83% contact<10cm **远超 ref 的 0%**。对于 desk005，ref 中的"搬运"其实是双手悬在桌面 12cm 上方"扶着走"。E032a 让手比 ref 更靠近桌子了。

**真正瓶颈**: 79% stable，且 base_pos=5→10 反而更差。说明不稳定的根因不是"CEM 不重视平衡"，可能是：
- 走路速度 0.6m/s 对 CEM horizon (0.8s) 来说步态规划困难
- hand_approach 把上半身前倾 → 重心偏移 → 某些步态切换时失稳
- 32 iter 可能不够（CEM 还没收敛就 commit 了）

**优化方向**:
1. 增加 num_samples/iterations → 更好的步态规划
2. 降低 hand_approach_sigma → 更柔和的吸引力（减少重心偏移）
3. 增加 horizon → CEM 能看到更远的未来步态

### box025 — 接触不足，但进一步提升面临姿态 vs 接触根本冲突

**差距**: ref 搬运期 85% contact<10cm，当前 E027d2 = 65%。差 20%。

**根本矛盾**: box025 的搬运需要深度弯腰(1.85rad)贴着箱面推。CEM 的 body tracking 尝试匹配这个姿态但做不到 100%。hand_approach 试图强制补偿这个差距 → 导致姿态更畸形。

**优化方向**:
1. Connect 约束: 手焊接到箱面 → 保证 100% 接触 → CEM 只优化走路 (E017 方案的非 anchored 版)
2. 更好的 body tracking: 提高 joint_rew / pos_rew → 让 CEM 更准确匹配弯腰姿态
3. 两阶段: 先优化行走稳定，再用更低 HA 补足接触

## 结论

- **desk005 更好优化**: 接触已达标，只需解决稳定性（方向明确：CEM budget/horizon/sigma）
- **box025 更难优化**: 需要同时深度弯腰+贴箱+走路，HA/body tracking 都有根本限制，可能需要 connect 约束方案
