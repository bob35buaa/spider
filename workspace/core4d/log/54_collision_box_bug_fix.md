# Collision Box Template Bug — 发现与修复

## 状态: ✅ 已修复 (2026-05-11)

## Bug 描述

所有 CORE4D case 的 `scene.xml` 中, **物体碰撞盒 (collision geom) 尺寸未按实际 mesh 调整**, 而是沿用了模板值 (box025/bucket005/desk005 的原始碰撞盒)。

### 根因

批量创建新 case 的 scene.xml 时, 使用 sed 从已有模板替换 mesh 路径, **但没有更新 collision box 的 size 属性**。每类物体分别继承了各自模板的碰撞盒:
- box 类: 继承 box025 的 `size="0.305 0.305 0.446"`
- bucket 类: 继承 bucket005 的 `size="0.148 0.205 0.143"`
- desk 类: 继承 desk005 的 `size="0.200 0.370 0.400"`

### 对实验的影响

1. **Contact 指标失真**: 碰撞盒过大时 (box023), 手在距视觉表面 ~13cm 就碰到隐形墙, Contact<10cm 指标被人为抬高
2. **碰撞盒过小时** (bucket003/007, desk007), 手可以穿透物体视觉表面, 物理交互不正确
3. **box025 的历史实验** (E001-E047): box025 碰撞盒偏小 0.85x, 意味着手需要更靠近物体中心才能碰到, 历史 Contact 指标可能偏低
4. **bucket010 碰撞盒形状错误**: Y/Z 尺寸互换 (1.86x in Y, 0.54x in Z), 物理上碰撞的是一个"扁平"版本的桶

## 修复方案

### 修复脚本

`workspace/core4d/scripts/convert/fix_collision_boxes.py`

**策略**: 碰撞盒 = 视觉 mesh AABB × 1.05 (5% margin)

- 读取 MuJoCo model 中 `object_visual` geom 的 mesh AABB 半尺寸
- 设置 `object_collision` geom 的 box size = AABB × 1.05
- 同时更新 scene.xml 和 scene_act.xml
