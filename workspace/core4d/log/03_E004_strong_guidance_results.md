## 根因确认

### SPIDER Contact Guidance 的设计意图
```python
# run_mjwp.py 第 320-325 行
for i in range(max_num_iterations):
    decay = guidance_decay_ratio ** i
    kp_i = base_kp * decay
    if i == max_num_iterations - 1:  # 最后一次迭代强制归零!
        kp_i = np.zeros_like(base_kp)
```

**最后一个优化迭代（iter=31）总是将物体执行器增益归零。** 实际物理步进使用最后一次迭代的增益状态 → kp=0 → 物体自由下落。

### 设计逻辑
这是有意为之：contact guidance 在优化迭代 0-30 中提供"引导弹簧"帮助 CEM 探索好的抓握姿态，最后一次迭代移除弹簧验证物理合规性。对于手指操作（OakInk）有效，因为手指摩擦力能维持物体。

### 对 humanoid_object 的影响
G1 的球形手碰撞体 (r=0.05m) 面对 61×61×89cm 的箱子：
- 接触面积极小 → 摩擦力不足
- 无抓握DOF → 无法形成力闭合
- 无论增益多大，最终步进时增益归零 → 物体必然落地
