## 📋 实验摘要

R001 对本地 InterPose 发布包做了全量、只读、可复现扫描，并对照论文和官方
数据构建代码判断其是否包含可直接进入 SPIDER 的人-物-人数据。

结论：

```text
NO_CONFIRMED_HOH_IN_RELEASE
confirmed_target_hoh_count = 0
```

本地有大量同 clip 的多 track 轨迹和文本筛选候选，但没有 object
identity/mesh/SE(3)、原始 frame IDs 或跨 track 同步证据。后续方向不是直接
转换发布 NPZ，而是基于官方开源 pipeline 从原视频重建完整 H-O-H 几何。

## 🔍 证据分析

### 论文

- 论文 Table 1 报告 `73,814` sequences、约 `15.7M` frames、`148.74 h`
- 论文明确只提取人体运动，不提取物体运动
- 多人视频按人体 bbox 逐人 caption
- multi-person collaboration 位于 HOI-Agent 应用章节

### 官方代码

- `post_process()` 按 person track 检查 `frame_ids` 和异常 gap
- 分段 key 为 `<person_idx>_<segment_idx>`
- AMASS exporter 仅写 `poses/trans/betas/num_betas/gender/fps/text`
- 最终 NPZ 不写 `frame_ids`、bbox、原视频 path 或 object state

### 本地发布包

- 每个 NPZ 只有一套 `(T,165)` SMPL-X 和 `(T,3)` translation
- 所有 NPZ schema 合格且 gender 为 `neutral`
- 同 clip prefix 可恢复 track group，但不能恢复原始同步关系
- tracker/person suffix 可能有身份碎片，不能当作物理人物主键

## 🎬 可视化

本轮没有生成 H-O-H 物理可视化。原因是发布包没有 object mesh/trajectory 和
跨 track frame sync；把两个人体 NPZ 强行叠加会产生不可验证、具有误导性的
“双人协作”画面。

实际审查替代为：

- 检查 strict/high-priority pair 的原始 caption 对
- 确认 `pass`、`together`、`another individual` 等 cue 存在明显误报
- 检查发布 exporter 丢弃 `frame_ids` 的代码路径

后续 W3/W4 一旦生成同步人体和物体 SE(3)，overlay MP4、contact sheet 和
object-only mesh/collision review 将成为硬 gate。
